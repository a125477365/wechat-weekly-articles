# wechat-weekly-articles

Skills for the weekly WeChat public-account articles, published as a magazine long image and saved as draft only (the user submits them).

- **Monday 00:00 — GitHub trending list.** The top 10 GitHub weekly trending repositories, one who + what sentence per entry, one magazine page per entry.
- **Friday 00:00 — AI design blind-test list.** The top 10 of the Contra Labs × BenchFlow Frontier Design Benchmark (https://contralabs.com/frontierdesign/leaderboard), one design entry per page, with Elo score, win rate and vote count. A new issue is made only when the ranking changes; a week with no change is skipped.

See `SKILL.md` for the full workflow: list building, magazine long-image format, draft-only saving through the browser, and handover.
